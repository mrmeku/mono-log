# Calendar Screen — Design Inspiration

The Calendar screen provides temporal navigation into the archive. A month grid with entry indicators; tap a day to see its entries. The calendar serves memory, not planning.

## Day One — Entry dots on month grid

The most direct reference for Mono Log's calendar. Day One uses colored dots on days with entries, with dot colors corresponding to journal colors.

- **day-one-calendar-view.png** — The calendar feature page image showing the month grid with colored entry indicators
- **day-one-calendar-ios.png** — Full iOS screenshot of the calendar view in action, showing entry dots and day navigation

**What to take**: Colored dots as entry indicators on the month grid. Tapping a date to drill into that day's entries. The calendar as a navigation tool into the past, not a planning tool. Clean, minimal month grid layout.

## Diarium — Calendar-as-home-screen

Diarium defaults to the calendar as its home screen, making temporal navigation the primary interaction.

- **diarium-screenshot-1.png** — iOS App Store screenshot showing the calendar-forward interface
- **diarium-calendar.webp** — The calendar view feature from the official site
- **diarium-device-showcase.webp** — Device showcase showing the calendar as the primary screen

**What to take**: The calendar occupying the top of the screen with a day preview below. The calendar AS the home screen rather than a secondary view. The functional, information-dense but clean layout.

## Fantastical — Temporal zoom hierarchy

Fantastical's view system (day → week → month → quarter → year) is the north star for future iterations of Mono Log's temporal navigation.

- **fantastical-dayticker.png** — The DayTicker: a horizontally-scrollable day strip with event indicators, paired with a scrollable event list below
- **fantastical-calendar-view.png** — The expandable calendar view showing month grid with colored dots per day
- **fantastical-month-view.png** — Full month view with event titles visible in day cells
- **fantastical-year-view.png** — Year heat map view where each day is colored by event density

**What to take**: The seamless temporal zooming (pull down DayTicker → month → year). The year heat map as a future aspiration. The way different zoom levels serve different needs (day = detail, month = navigation, year = patterns). The colored-dot-per-day pattern at the month level.
