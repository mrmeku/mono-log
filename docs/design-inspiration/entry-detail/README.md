# Entry Detail Screen — Design Inspiration

The Entry Detail screen displays a single distilled entry. Key elements: distilled Markdown output, timestamp, duration, and a toggle to switch between distilled and raw transcript views.

## Cleft — Transcript toggle and formatted notes

The closest existing analog to Mono Log's core distillation UX. Cleft records voice, transcribes it, then reformats it into clean notes.

- **cleft-transcript-view.jpeg** — The raw transcript view, showing timestamped speech-to-text output
- **cleft-formatted-notes.jpeg** — The formatted/distilled view of the same recording, showing how AI restructures the transcript
- **cleft-visual-editor.png** — The visual Markdown editor showing the final note output

**What to take**: The transcript ↔ formatted toggle pattern. The side-by-side concept of "what you said" vs. "what it means." The clean, readable output. The way metadata (timestamp, duration) sits in the header without competing with content.

## Day One — Clean entry detail with metadata header

Day One's entry detail is the gold standard for full-screen journal entry reading.

- **day-one-home-tab.png** — The home tab showing entry cards with metadata (date, location, weather)
- **day-one-editor.png** — The entry editor/detail view with rich text formatting

**What to take**: The clean, full-screen reading experience. Metadata in a compact header (timestamp, location, weather). The way the entry body fills the screen with generous typography. The toolbar at the bottom for secondary actions.
