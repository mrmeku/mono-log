# Today (Home) Screen — Design Inspiration

The Today screen is a capture-first landing screen. The record button is the most prominent element, with today's entries listed below.

## Cleft — Record-forward design

The primary reference for Mono Log's recording UX. Cleft is a voice-first capture app with one-tap recording and no setup friction.

- **cleft-voice-recording.png** — iPhone voice messaging interface, showing the single-action recording paradigm
- **cleft-ai-scribe.png** — Full-screen app view showing the AI note transformation flow (record → transcribe → distill)
- **cleft-app-overview.png** — App overview showing the minimal, record-forward home screen

**What to take**: The record button's prominence and the "tap and talk" immediacy. No modal, no prompt, no "what kind of entry?" — just record.

## Apple Journal — Single-screen simplicity

Apple's aggressively simple journaling app. One screen, one feed, one + button.

- **apple-journal-suggestions.jpg** — The new entry flow with Journaling Suggestions (personalized moments from your day)
- **apple-journal-home.jpg** — The journal feed and entry creation interface
- **apple-journal-overview.jpg** — Wide overview of the app's screens and interface

**What to take**: The calm, minimal home screen with almost no chrome. The + button at the bottom. The empty state that doesn't overwhelm. The warm, off-white canvas feel.
