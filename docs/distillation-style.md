# Distillation Style

## Inspiration

Mono Log's distillation style is directly inspired by [Cleft Notes](https://www.cleftnotes.com/). Cleft's output reads like "a buddy telling you what they understood from what you said" — faithful to the original but rephrased for clarity and reorganized for scannability.

## Output Format

Each voice recording produces a single Markdown document with:

- **Auto-generated headings** — the AI infers logical section breaks and names them; the user never dictates structure
- **Bullet points and checklists** where the speaker was listing things
- **Paragraphs** where the speaker was narrating or processing
- **Logical grouping** — if the speaker bounced between topics, related thoughts are clustered together

## Principles

- **Context-dependent, not templated.** The output structure adapts to what was said. A vent session looks different from a brainstorm which looks different from a to-do dump.
- **Reorganized, not just cleaned up.** The distillation clusters and restructures, it doesn't just fix grammar.
- **Faithful to what was said.** The output mirrors the speaker's meaning and tone. It does not editorialize, add advice, or inject positivity. It reflects, it doesn't coach.
- **Concise.** A 30-minute ramble should become something you can scan in under a minute.
